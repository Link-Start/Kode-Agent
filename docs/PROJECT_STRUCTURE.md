# Kode Project Structure

Kode is organized as a monorepo-style workspace, but is published as a single npm package (`@shareai-lab/kode`).

## Build + runtime model

- **Dev/build toolchain**: Bun (required for development).
- **Production runtime baseline**: Node.js (no Bun required for users).
- **Entry wrapper behavior**: prefer cached native binary → fallback to Node.js runtime (`dist/index.js`).

## Repository layout

```
.
├── apps/
│   └── kode/                    # Unified dispatch + build entrypoints
│       └── src/
│           ├── index.ts         # Lightweight dispatcher (help-lite/version early-return)
│           ├── bootstrapEnv.ts  # App-level bootstraps (packaged/yoga wasm)
│           └── entrypoints/     # Build entrypoints → dist/entrypoints/*
├── packages/
│   ├── core/                    # Engine + shared domain modules (query/permissions/context/etc.)
│   ├── protocol/                # Schema-first protocol + event models
│   ├── tools-builtin/           # Built-in tools (capabilities + structured outputs)
│   ├── host-cli/                # CLI host wiring (Commander + Ink integration)
│   ├── host-acp/                # ACP host (JSON-RPC over stdio)
│   ├── host-mcp/                # MCP host (server/client adapters)
│   ├── daemon/                  # Local daemon (HTTP/WS + WebUI hosting) + client SDK
│   ├── config/                  # Config system (profiles/pointers/migrations)
│   ├── runtime/                 # Runtime interface types (fs/spawn/env/etc.)
│   ├── runtime-node/            # Node.js runtime implementation (baseline)
│   └── runtime-bun/             # Optional Bun runtime implementation
├── ui/
│   ├── ink/                     # Ink TUI components + screens (presentation layer)
│   └── web/                     # Built-in WebUI (Vite/React), served by the daemon
├── scripts/                     # Build/publish tooling
├── docs/                        # User + developer documentation
├── new_plan/                    # vNext architecture plan + progress tracker
├── examples/                    # SDK/daemon/WebUI integrations and PoCs
├── cli.js                       # Node wrapper (generated by build)
├── cli-acp.js                   # ACP wrapper (generated by build)
├── tsconfig.json                # TS config + minimal `#...` path aliases
└── package.json                 # Single-package publish config + subpath exports
```

## Outputs

`bun run build` produces:

- `dist/index.js` (Node ESM entry)
- `dist/entrypoints/*` (cli/acp/mcp/mcpServer/daemon)
- `dist/sdk/*` (subpath exports: `@shareai-lab/kode/core`, `.../protocol`, `.../daemon-client`, `.../runtime`, `.../runtime-node`)
- `dist/webui/*` (if `ui/web` build is available)
- `cli.js` / `cli-acp.js` (runtime wrappers)

## Useful commands
