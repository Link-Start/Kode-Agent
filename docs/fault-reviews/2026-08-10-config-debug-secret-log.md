# 配置调试日志泄露风险复盘

## 现象

开启 `KODE_DEBUG_CONFIG` 后，配置加载事件会写出全局配置文件前 100 个字符。模型 profile 允许 `apiKey`，因此密钥可能进入终端、CI 日志或日志采集系统。

## 根因

调试事件将排障便利性置于配置数据最小化之前，直接记录了未分类的原始文件内容；其余事件只需文件路径、长度和解析后的键名即可定位加载问题。

## 修复

删除 `contentPreview` 字段，保留不含内容的文件路径与字节长度；新增回归测试，以隔离的临时配置和测试占位密钥验证调试输出不包含文件内容。

## 防回归

任何配置、请求或认证状态的调试事件只允许记录结构元数据和明确脱敏的字段，禁止记录原始正文或可逆凭据片段。
